## Failures and defects

1. **[FAIL] rustfmt, 1 hunk**: `apps/linux/app/src/main.rs:57`. `eprintln!("smoke: {} QML warning(s)", bridge::smoke_log::qml_warnings());` exceeds line width. Fix: `cargo fmt --manifest-path apps/linux/Cargo.toml --all`. Formatting only, no behavior change. Not applied by me (scope).

2. **[DEFECT, diagnostics] QML warning text swallowed in `--smoke`**: `app/cpp/smoke_log.cpp` `handler()` forwards to `g_previous` only if non-null. Qt returns nullptr from `qInstallMessageHandler` when default handler was active, so the default output is dropped. Observed: negative run printed only the count line, no QML error text. Smoke still fails correctly, but the developer gets no reason. Fix: when `g_previous == nullptr`, write `msg` to stderr (or call the default output path) before returning.

3. **[NOTE] Concurrent edits in root `core/`**: `git status` shows uncommitted changes in `core/fsync-proto` (`platform.rs`, `device_list.rs`, `lib.rs`), `core/fsync-ffi/src/types_device.rs`, `core/fsync-core/tests/trust_manager.rs`. Another session or agent was editing these during this run (a process ran a python patch script against them). Checks 4, 6a, 6b ran against this working tree, not clean HEAD. Re-run 4/6 on a clean tree before the phase is signed off.
