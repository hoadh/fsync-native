## Bugs / findings (file:line)
1. **Spec deviation: `send` is refused, not queued, when signed out.** Plan requires `show`/`send` queued until signed in; `clip-*` no queue. Code: `apps/linux/app/src/engine/ipc_handler.rs:25-35` returns `signed-out` immediately for `Send`. Repro: `--send <file>` while signed out -> `fsync: signed-out`, exit 1. Medium: a launcher drop while signed out is lost. Fix or update plan.
2. **Test-only env leakage risk (process, not code):** none in code. See Critical Issues.
3. **Low: `--data-dir` consumes the next argument unconditionally.** `apps/linux/app/src/cli_args.rs:32-35`. `--data-dir --background` sets data dir to `--background`. Code read only, not executed. Suggest reject values starting with `--`.
4. **Low: raw io error text on IPC connect failure.** Second launch with long `XDG_RUNTIME_DIR` prints `fsync: cannot reach the running instance: ipc io: path must be shorter than SUN_LEN`. Suggest explicit message and/or fallback path check before bind (`platform/src/ipc/` client/server). Code path not located in detail.
5. **Build warning: gold linker** (see above).
